}

::1-2 [З1.1]::Какой оператор используется для сравнения значений в Python? {
  ~print()
  ~if
  =\=\=
  ~for
  ####Оператор `\=\=` используется для сравнения значений. Например, `x \=\= 5` проверяет, равен ли `x` числу 5.
}

::1-3 [З1.1]::Что делает цикл `for` в Python? {
  ~Повторяет выполнение кода до тех пор, пока условие не станет ложным.
  =Выполняет код определенное количество раз.
  ~Сравнивает два значения.
  ~Присваивает значение переменной.
  ####Цикл `for` повторяет выполнение кода определенное количество раз. Например, `for i in range(5)\: print(i)` выведет числа от 0 до 4.
}

::1-4 [З1.1]::Какой оператор используется для выполнения блока кода при выполнении определенного условия? {
  ~while
  =if
  ~for
  ~else
  ####Оператор `if` используется для выполнения блока кода при выполнении определенного условия. Например, `if x > 0\: print('x положительное')` выполнит команду, если `x` больше 0.
}

}

::1-8 [З1.1]::Какой оператор используется для проверки условия в Python? {

}
